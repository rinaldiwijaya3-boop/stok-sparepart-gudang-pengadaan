Daftar stok menipis & usulan pembelian

Usulan kuantitas dihitung dari batas minimum dikurangi stok yang tercatat.
Isi Target Stok (Buffer) pada Edit Item. Usulan pembelian = Target Stok (Buffer) − Stok tersedia, dan tidak pernah kurang dari nol. Item dengan stok kosong/negatif perlu diverifikasi dulu. Batas minimum tetap dipakai sebagai peringatan stok menipis.

Import / Export data

Gunakan untuk memuat master stok baru atau menyimpan salinan data aplikasi.

Aplikasi ini menggunakan login dan database bersama Supabase. Hanya akun admin yang dapat mengubah data; akun viewer hanya dapat membaca. Pastikan SQL setup dan kebijakan RLS sudah dijalankan di Supabase.
Prototype awal untuk evaluasi alur kerja. Periksa dan cocokkan master dengan stok fisik sebelum dipakai untuk keputusan operasional resmi.
